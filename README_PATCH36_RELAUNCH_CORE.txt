ANIME BATTLE MULTIVERSE — PATCH36_RELAUNCH_CORE
================================================

Это не косметический hotfix, а перезапуск внешней оболочки и критической логики бота.
Все 17 641 карты, существующие аккаунты, коллекции, кланы, арены, PvP, рейды,
MultiPass, кейсы, Stars-платежи и админка сохранены.

ГЛАВНОЕ, ЧТО ИЗМЕНЕНО
----------------------

1. Новый главный экран
- Компактное меню вместо стены одинаковых кнопок.
- Основные разделы: Призыв, Коллекция, Битвы, События, Награды, Профиль.
- Остальные функции собраны в разделе «Ещё».
- На экране сразу видны вселенная, прогресс коллекции, сила, попытки, валюты,
  ежедневная награда, таймер призыва и клан.
- Добавлен фирменный баннер Anime Battle Multiverse.
- Постоянная нижняя клавиатура: Призыв / Коллекция / Битвы / Меню.

2. Полностью переделано выпадение карты
- Карта приходит одним аккуратным визуальным сообщением.
- Показываются редкость, вселенная, форма, сила, уровень, новый экземпляр или
  дубликат, прогресс коллекции и таймер следующего бесплатного призыва.
- Для 896 карт используются настоящие изображения из media_packs.
- Для остальных карт автоматически создаётся фирменная карточка, поэтому даже
  мифические карты больше не выпадают голым текстом.
- Бесплатный призыв теперь участвует в pity/гаранте.

3. Более чистая навигация
- Навигационные окна автоматически убираются, но награды, карточки и боевые логи
  не стираются без причины.
- Исправлены кнопки, которые раньше не имели обработчика:
  «Оплаты pass» и «Хранилище» в админке.
- Добавлены /storage и /flush_data владельцу.
- Добавлен глобальный обработчик ошибок: одна сломанная кнопка не должна ронять
  polling, а Telegram-spinner не должен висеть бесконечно.

4. Защита от двойных нажатий
- Действия одного игрока выполняются последовательно.
- Быстрый двойной клик больше не должен дважды списывать валюту, выдавать награду,
  открывать кейс или проводить повторный призыв.
- Разные игроки при этом продолжают обслуживаться параллельно.

5. Исправлена реферальная система
- Работает прямая ссылка вида https://t.me/ИМЯ_БОТА?start=ref_TELEGRAM_ID.
- Новый игрок получает +300 фисташек и +1 попытку.
- Пригласивший получает +500 фисташек и +3 попытки.
- Повторная активация не выдаёт награду второй раз.
- Игроки автоматически добавляются друг другу в друзья.
- Счётчики приглашений и дневной прогресс обновляются корректно.

6. Исправлены промокоды
- max_uses теперь реально ограничивает общее количество активаций.
- Поддерживаются награды: фисташки, драконит, попытки и карта.
- Один игрок не может повторно забрать тот же код, кроме владельца для тестов.

7. Безопасное хранение прогресса
- Neon/PostgreSQL является главным источником данных, если DATABASE_URL настроен.
- Бот больше не объединяет старые JSON/SQLite/Neon-копии по максимальным балансам.
  Поэтому потраченная валюта, снятый бан или истёкший Premium не должны
  «воскресать» после перезапуска.
- Старые backup-файлы используются только для ручного возвращения отсутствующих
  аккаунтов; существующие аккаунты не перезаписываются старыми балансами.
- Добавлена блокировка параллельных сохранений.
- Если Neon настроен, но временно недоступен при запуске, бот безопасно остановится,
  а не запустится на старой локальной копии и не затрёт облачную базу.
- Если запись в Neon не прошла, сохранение считается неуспешным, DATA остаётся dirty,
  и повторная запись ставится в очередь.
- При выключении выполняется обязательный финальный flush.

8. Безопасность прав
- Удалён заранее прописанный чужой Telegram ID из прав «правой руки».
- right_hand_ids.txt по умолчанию пустой.
- Права выдаются только через right_hand_ids.txt или переменные RIGHT_HAND_ID /
  RIGHT_HAND_IDS.

9. Telegram Stars
- Проверяются payload, Telegram ID покупателя, валюта XTR и точная сумма.
- Повторная обработка одного charge ID заблокирована.
- Premium MultiPass после подтверждённого Telegram-платежа открывается автоматически
  до 100 уровня; ручное ожидание владельца для новых платежей убрано.
- Pending updates больше не удаляются при рестарте, чтобы не потерять событие
  successful_payment.

10. Единый язык интерфейса
- «Бесплатный сундук» переименован в «Бесплатный призыв» там, где фактически
  выдаётся одна карта.
- Кнопки и команды приведены к единой терминологии «Призыв / Призвать карту».
- Telegram custom emoji в кнопках отключены по умолчанию, потому что на разных
  клиентах они отображались нестабильно. Обычные emoji работают везде.
- При необходимости custom emoji можно вернуть переменной CUSTOM_BUTTON_EMOJI=1.

ОБЯЗАТЕЛЬНЫЕ ПЕРЕМЕННЫЕ НА RENDER
---------------------------------

BOT_TOKEN=токен_бота_из_BotFather
DATABASE_URL=строка_подключения_Neon_PostgreSQL

Необязательные:
OWNER_ID=ваш_Telegram_ID
RIGHT_HAND_IDS=ID1,ID2
DATA_DIR=/var/data              только если у сервиса есть Persistent Disk
CUSTOM_BUTTON_EMOJI=0           рекомендуется оставить 0
PORT=10000                      Render обычно задаёт сам

КАК УСТАНОВИТЬ
--------------

1. Сделайте backup текущего репозитория и Neon-базы.
2. Замените содержимое корня проекта файлами из этого архива.
3. Не удаляйте свои Environment Variables в Render.
4. Проверьте BOT_TOKEN и DATABASE_URL.
5. Выполните Clear build cache & deploy.
6. После запуска откройте /storage и убедитесь, что Neon доступен.

МИНИМАЛЬНАЯ ПРОВЕРКА ПОСЛЕ DEPLOY
---------------------------------

1. /start — появляется новый главный экран.
2. Нажать «Призыв» — приходит визуальная карта.
3. Открыть «Коллекция» и карточку.
4. Проверить «Битвы», «События», «Награды» и «Ещё».
5. Создать тестовую реферальную ссылку и открыть её новым аккаунтом.
6. Проверить промокод с маленьким max_uses.
7. В админке открыть «Хранилище» и «Оплаты pass».
8. Выполнить /flush_data и снова /storage.

ВАЖНОЕ ОГРАНИЧЕНИЕ
------------------

В базе 17 641 карта, но настоящие изображения есть только у 896 карт. Код не может
сам создать оригинальные арты персонажей. Для остальных используется аккуратная
фирменная карточка-заглушка. Чтобы заменить её настоящим изображением, положите в
media/cards файл с именем ID карты, например:

media/cards/goku_black_rose.jpg
media/cards/goku_black_rose.png
media/cards/goku_black_rose.gif

После этого бот автоматически будет использовать реальное медиа.
