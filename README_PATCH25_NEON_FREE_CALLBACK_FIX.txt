PATCH25_NEON_FREE_CALLBACK_FIX

Что исправлено:
1. Критический Telegram callback_data баг:
   - длинные card_id больше не вставляются в кнопки напрямую;
   - коллекция, улучшение, фрагменты, выбор колоды и ручная команда используют короткие коды карт;
   - старые длинные callback тоже поддерживаются через resolve_card_id().

2. Render Free / без платного Persistent Disk:
   - Neon/PostgreSQL через DATABASE_URL остаётся главным постоянным хранилищем;
   - локальный JSON/SQLite остаётся только кэшем/fallback;
   - если /var/data недоступен, бот не падает и уходит во временный fallback;
   - /storage показывает, что Render Disk не обязателен, если Neon подключён.

3. Админка игроков:
   - добавлены два режима: «Живые игроки» и «Все из базы»;
   - «Все из базы» показывает записи из DATA/Neon, включая inactive/blocked/frozen/deleted;
   - открытие профиля игрока идёт безопасно через callback внутри бота, без Telegram privacy button issue.

4. Оспаривание боя:
   - кнопка «Оспорить» после боя теперь отправляет быстрый спор владельцу/правой руке;
   - владелец получает кнопки: профиль, +1000, ответить, отклонить;
   - в спор добавляется контекст последнего боя, если он есть в active_battles.

5. Рейды:
   - RAID_DURATION_DAYS изменён с 7 на 1, чтобы боссы стали дневными, как в ТЗ PATCH13/PATCH25.
